# 这个工具能证明什么，不能证明什么

写这一页是因为最容易犯的错不是"算错了"，而是"算对了以后解读错了"。

## 它能做的

**量出一张正面照上左右脸的几何差异。** 单位是"内眼角间距"的倍数，可重复、有误差范围。
同一台设备、同一光位下重复测同一个人，分数的波动可以量化出来；超出这个波动才叫变化。

**量出面部若干区域的颜色差异。** LAB 空间里的区域间差值，附饱和像素比例。

**把每次结果和自己的历史比。** 注意是和自己比。跨人比较在这个精度上没有任何意义。

## 它不能做的

**不能判断有没有卒中。** 急性期的面部表现是运动体征（口角歪斜、一侧下垂），
本工具量的是静态几何差异和颜色，两者不是同一个信号。而且随访是按次测量的，
卒中发生在两次测量之间，没有任何一次测量落在事件发生的时刻。

**不能给出"风险百分比"。** 那需要一个有结局数据的队列来标定，我们没有。

**不能替代医生。** 这句话写进了结果页、免责声明页和页脚，也写进了测试。

**不能跨设备比。** 不同手机的前摄有不同的焦距、色彩处理和降噪强度。换设备等于换了一把尺子。
真要换，得先用同一批人做一次设备间的配对测量做桥接，不能直接把旧基线搬过去。

## 精度边界（诚实版）

- **几何通道**：镜像点配对的残差中位数是 0.0059 个眼距单位，量表本身是稳定的。
  但 `a_ref`（0.0536）和 `a_max`（0.1983）来自 794 张正脸，样本来源单一，
  **换成别人的数据，分数的绝对位置就要重标**。代码里标了 `provisional: true`。
- **颜色通道**：同一条件下重复拍摄，稳定帧之间的色差噪声约 0.29 ΔE；
  自动曝光跳变一次，同一块皮肤的读数能差到 4.17 ΔE。也就是说噪声不是高斯的，是混合分布，
  一次曝光跳变就足以淹没真实的生理信号。这是本项目不敢对颜色结果下任何结论的直接原因。
- **质量门控**：阈值是在"固定工位、固定距离"的对照集里标的。手持自拍、不同身高、不同房间，
  误拒率和漏放率都会变差，没有重标之前不要相信门控的通过率。

## 关于那个 0.818

`core/asymmetryModel.js` 里的模型 AUC 是 0.818，这是在内部数据上做随机划分评估得到的。
**这个数字不能作为泛化性能引用**，原因见 `DATA-AND-ETHICS.md`：那批数据的标签与采集来源高度重叠。
把随机划分的交叉验证当成验证，是这类项目最常见也最容易被审稿人抓住的错误。

## 结论

拿它当一把有刻度的尺子，别拿它当判断。要做出判断，
至少要先做完三件事：测量噪声底明确且明显小于目标信号；阳性对照（已知生理变化）能被稳定捕捉；
特征版本冻结、在同源纵向数据上验证过。三件都没做完之前，任何结论性输出都是越界。
